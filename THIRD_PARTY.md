# Third party

## Runtime dependencies

- Astro (MIT)
- Tailwind CSS (MIT)

## Color palette

- The light and dark palette is inspired by WhatsApp (green accent, dark blue-gray surfaces). It is a design reference only, not affiliated with or endorsed by WhatsApp.

## Fonts

None bundled. The site uses the system font stack, so there is no font license
or subsetting concern. If a self-hosted OFL font is added later, record its name,
license, and subset here.

## Map

- OpenStreetMap tiles via the public embed endpoint (openstreetmap.org). Tiles
  are used under the OpenStreetMap tile usage policy and the data is ODbL.
  Attribution "© OpenStreetMap contributors" is shown and linked.
